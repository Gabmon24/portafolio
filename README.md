---

## 🌟 Características Principales

- 🌙 **Tema Claro / Oscuro (Dark Mode):** Alternador dinámico de temas con persistencia en `localStorage`.
- 📱 **Diseño 100% Responsivo:** Adaptado para teléfonos móviles, tablets y computadoras de escritorio.
- ⚡ **Sin dependencias pesadas:** Construido nativamente con HTML5, CSS Variables, Flexbox/Grid y JavaScript ES6+.
- 🎨 **Componentes Interativos:** Tarjetas de proyectos con enlaces a repositorios de GitHub, tarjeta de perfil tipo IDE de código y menú hamburguesa en móviles.
- 🚀 **Desplegado en GitHub Pages:** Alojado de manera gratuita y disponible públicamente.

## 🚀 Despliegue en GitHub Pages

Para publicar este sitio web en internet de forma gratuita a través de GitHub Pages:

1. Ve a tu repositorio en GitHub: `https://github.com/Gabmon24/portfolio`.
2. Haz clic en la pestaña **Settings** (Configuración).
3. En el menú lateral izquierdo, haz clic en **Pages**.
4. En **Build and deployment > Source**, selecciona **Deploy from a branch**.
5. En **Branch**, selecciona `main` y la carpeta `/ (root)`, luego haz clic en **Save**.
6. ¡Listo! En un par de minutos tu sitio estará en vivo en: `https://gabmon24.github.io/portfolio`.
